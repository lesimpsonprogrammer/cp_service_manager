Data extraction
DATA
Pulling records out of a source system in a structured, repeatable format.
Data transformation
DATA
Converting extracted data into the structure, format, and code values the destination requires.
Data migration
DATA
Moving data from a legacy system into a new one as part of a defined cutover.
Data integration
DATA
Keeping two or more systems in agreement through an ongoing exchange of records.
ETL
DATA
Extract, transform, load — the data is shaped before it lands in the destination.
ELT
DATA
Extract, load, transform — raw data lands first and is shaped in the destination.
Field mapping
DATA
The documented relationship between a source field and its destination field, including any conversion rule.
Normalization
DATA
Standardizing values so the same real-world thing is represented identically everywhere.
Deduplication
DATA
Identifying and resolving records that represent the same person or entity.
Data validation
DATA
Automated and manual checks confirming loaded data matches the source in count, total, and logic.
Reconciliation
DATA
Comparing control totals between source and destination to prove nothing was lost or duplicated.
Effective dating
DATA
Storing records with the dates a value was true, so history reflects what was accurate at the time.
Data dictionary
DATA
The authoritative list of every field in a dataset with its definition, type, source, and owner.
Data lineage
DATA
The traceable path of a data element from origin through every transformation to its destination.
Data governance
DATA
The ownership, rules, and review process that keep data accurate and defensible over time.
Data steward
DATA
The person responsible for the day-to-day quality and definitions of a given dataset.
Data owner
DATA
The accountable business leader who approves access, definitions, and changes to a dataset.
Master data
DATA
Core shared entities — employees, locations, cost centers — used across multiple systems.
Reference data
DATA
Controlled code lists such as pay codes, state codes, or job families used to classify records.
Transactional data
DATA
Event-level records such as pay runs, time punches, or benefit elections.
Metadata
DATA
Data about data — field types, formats, sources, and update times.
Schema
DATA
The structural definition of tables, fields, types, and relationships in a dataset.
Primary key
DATA
The field that uniquely identifies each record in a table.
Foreign key
DATA
A field that references the primary key of another table, linking related records.
Delimiter
DATA
The character separating fields in a flat file, commonly a comma, pipe, or tab.
Flat file
DATA
A plain text export with one record per line and no relational structure.
CSV
DATA
Comma-separated values — the most common interchange format for system exports.
Staging environment
DATA
A non-production copy where loads are tested before touching live data.
Cutover
DATA
The controlled window in which processing moves from the legacy system to the new one.
Parallel testing
DATA
Running the new system alongside the old for one or more cycles and comparing outputs.
Control total
DATA
An agreed count or sum used to verify a load moved exactly what it should have.
Data profiling
DATA
Examining a source to learn its actual contents, ranges, gaps, and anomalies.
Data quality
DATA
The degree to which data is accurate, complete, consistent, timely, and fit for its use.
Data cleansing
DATA
Correcting or removing inaccurate, incomplete, or improperly formatted records.
Record matching
DATA
Applying rules to determine whether two records describe the same entity.
Golden record
DATA
The single agreed version of an entity assembled from multiple sources.
Data warehouse
DATA
A structured, query-optimized store for reporting across integrated sources.
Data lake
DATA
A store that holds raw data in its native format until a use case requires shaping.
Data mart
DATA
A subject-specific slice of a warehouse serving one function, such as HR or finance.
API
DATA
A defined interface allowing one system to request or send data to another programmatically.
REST
DATA
A common API style using standard HTTP methods and structured request and response bodies.
Webhook
DATA
An outbound event notification sent by a system the moment something happens.
Connector
DATA
A prebuilt integration between two named platforms, maintained as a product.
Batch processing
DATA
Moving records in scheduled groups rather than one at a time.
Incremental load
DATA
Transferring only records changed since the last run.
Full load
DATA
Replacing the destination dataset with a complete refresh from the source.
Idempotency
DATA
A property ensuring that repeating the same operation produces no additional effect.
Encryption at rest
DATA
Protecting stored data so it cannot be read without the key, typically AES-256.
Encryption in transit
DATA
Protecting data as it moves across a network, typically using TLS.
PII
DATA
Personally identifiable information — data that can identify a specific individual.
Data retention
DATA
The defined period a dataset is kept before it is archived or destroyed.
Audit trail
DATA
A retained, tamper-evident log of who accessed or changed data and when.
HRIS
HR
Human resources information system — the system of record for employee data.
HCM
HR
Human capital management — a broader suite covering HR, payroll, talent, and time.
Applicant tracking system
HR
The system managing job postings, candidates, and hiring workflow.
Onboarding
HR
The process of bringing a new hire from offer acceptance to productive work.
Offboarding
HR
The process of closing out an employee's access, pay, benefits, and records at exit.
Employee lifecycle
HR
The stages an employee moves through from applicant to alumnus.
Job architecture
HR
The structured framework of job families, levels, and titles across an organization.
Job classification
HR
Assigning a role to a defined level, family, and pay structure.
Exempt
HR
A role exempt from overtime requirements under applicable wage and hour law.
Non-exempt
HR
A role entitled to overtime pay for hours worked beyond the statutory threshold.
FLSA
HR
The Fair Labor Standards Act, governing minimum wage, overtime, and recordkeeping.
Compensation band
HR
The minimum, midpoint, and maximum pay range assigned to a job level.
Pay equity
HR
Ensuring comparable roles are paid comparably, absent legitimate differentiating factors.
Performance review
HR
A structured evaluation of an employee's results and behaviors over a defined period.
Succession planning
HR
Identifying and preparing internal candidates for critical roles.
Headcount
HR
The number of people employed, counted individually regardless of hours.
FTE
HR
Full-time equivalent — headcount expressed in full-time-hour units.
Attrition
HR
Employees leaving the organization, whether voluntarily or not.
Turnover rate
HR
Separations in a period divided by average headcount for that period.
Time to fill
HR
Days from requisition approval to offer acceptance.
Cost per hire
HR
Total recruiting spend divided by the number of hires in a period.
Employee engagement
HR
The measured degree of commitment and discretionary effort across a workforce.
Employee relations
HR
The function handling workplace concerns, investigations, and conflict resolution.
Progressive discipline
HR
A documented escalation of corrective action prior to termination.
Handbook
HR
The written record of the policies governing employment at an organization.
Policy acknowledgment
HR
An employee's recorded confirmation that a policy was received and read.
I-9
HR
The federal form verifying an employee's identity and authorization to work.
E-Verify
HR
The electronic system some employers use to confirm work authorization.
EEO-1
HR
The annual federal report of workforce demographics required of larger employers.
ADA accommodation
HR
An adjustment enabling a qualified individual with a disability to perform a role.
FMLA
HR
The Family and Medical Leave Act, providing eligible employees protected unpaid leave.
PTO accrual
HR
The rate at which paid time off is earned across a pay period or year.
Leave of absence
HR
An approved period away from work, paid or unpaid, with defined return terms.
Open enrollment
HR
The annual window in which employees elect or change benefit coverage.
Benefits eligibility
HR
The rules determining which employees may enroll in which plans and when.
COBRA
HR
Continuation of group health coverage after a qualifying event, at the participant's cost.
Total rewards
HR
The full value of pay, benefits, and non-cash programs offered to employees.
Org chart
HR
The mapped reporting structure of an organization.
Span of control
HR
The number of direct reports a manager carries.
Workforce planning
HR
Forecasting the roles, skills, and headcount an organization will need.
Multi-state workforce
HR
Employees working across states, triggering varied tax, leave, and labor obligations.
Gross pay
PAYROLL
Total earnings before any taxes or deductions are applied.
Net pay
PAYROLL
Take-home pay after all taxes and deductions.
Pay period
PAYROLL
The span of time covered by a single paycheck.
Pay frequency
PAYROLL
How often employees are paid — weekly, biweekly, semimonthly, or monthly.
Payroll register
PAYROLL
The detailed record of every employee's earnings, taxes, and deductions for a run.
Earnings code
PAYROLL
A code classifying a type of pay, such as regular, overtime, or bonus.
Deduction code
PAYROLL
A code classifying an amount withheld, such as a benefit premium or garnishment.
Pre-tax deduction
PAYROLL
An amount withheld before taxes are calculated, reducing taxable wages.
Post-tax deduction
PAYROLL
An amount withheld after taxes are calculated, with no effect on taxable wages.
Imputed income
PAYROLL
The taxable value of a non-cash benefit added to an employee's wages.
Garnishment
PAYROLL
A court- or agency-ordered withholding remitted to a third party.
Wage assignment
PAYROLL
A voluntary employee authorization to withhold and remit part of their pay.
Withholding
PAYROLL
Tax amounts deducted from wages and remitted to taxing authorities.
W-4
PAYROLL
The federal form on which an employee sets their withholding elections.
W-2
PAYROLL
The annual statement of an employee's wages and withheld taxes.
1099-NEC
PAYROLL
The annual statement of compensation paid to a non-employee contractor.
Form 941
PAYROLL
The quarterly federal return reporting withheld income and FICA taxes.
Form 940
PAYROLL
The annual federal return reporting unemployment tax liability.
SUTA
PAYROLL
State unemployment tax, assessed at an experience-rated employer rate.
FUTA
PAYROLL
Federal unemployment tax, paid by the employer on a limited wage base.
FICA
PAYROLL
Social Security and Medicare taxes, shared between employee and employer.
Medicare surtax
PAYROLL
The additional Medicare withholding applied above a statutory wage threshold.
Taxable wage base
PAYROLL
The annual earnings ceiling above which a given tax no longer applies.
Multi-state taxation
PAYROLL
Applying the correct withholding when work and residence states differ.
Reciprocity agreement
PAYROLL
An arrangement letting an employee be taxed only in their state of residence.
Local tax jurisdiction
PAYROLL
A city, county, or district levying its own payroll tax.
Direct deposit
PAYROLL
Electronic transfer of net pay to an employee's bank account.
Pay card
PAYROLL
A reloadable card used to deliver wages to employees without bank accounts.
Off-cycle payroll
PAYROLL
A pay run outside the normal schedule, used for corrections or terminations.
Retroactive pay
PAYROLL
Wages owed for a prior period because of a late rate change or correction.
Shift differential
PAYROLL
Additional pay for working a less desirable shift.
Overtime
PAYROLL
Premium pay owed for hours worked beyond the statutory threshold.
Double time
PAYROLL
A premium rate of twice base pay, required by some state laws or agreements.
Blended rate
PAYROLL
A weighted average hourly rate used when an employee works at multiple rates.
Accrual
PAYROLL
An amount earned but not yet paid, recognized in the period it was incurred.
General ledger mapping
PAYROLL
Assigning payroll amounts to the accounts finance uses to post them.
Payroll funding
PAYROLL
Transferring cash to cover net pay, taxes, and remittances before a run settles.
Year-end processing
PAYROLL
Closing the tax year, reconciling wages, and producing W-2s and 1099s.
Amended return
PAYROLL
A corrected tax filing submitted after an error is found in an original.
Payroll audit
PAYROLL
A structured review of pay data, filings, and controls for accuracy and compliance.
Certified payroll
PAYROLL
Weekly wage reporting required on many government-funded construction contracts.

PROJECT MANAGEMENT
The document defining scope, deliverables, timeline, and responsibilities for an engagement.
Scope creep
PROJECT MANAGEMENT
Uncontrolled growth of project scope without matching time or budget.
Requirements gathering
PROJECT MANAGEMENT
Collecting and documenting what the business needs the solution to do.
Configuration workbook
PROJECT MANAGEMENT
The vendor-supplied document capturing every system setting a client must decide.
Discovery
PROJECT MANAGEMENT
The early phase spent understanding current state, constraints, and objectives.
Design phase
PROJECT MANAGEMENT
Translating requirements into a documented target configuration and process.
Build phase
PROJECT MANAGEMENT
Configuring, developing, and assembling the solution described in design.
UAT
PROJECT MANAGEMENT
User acceptance testing — business users confirm the system meets requirements.
Test script
PROJECT MANAGEMENT
A written sequence of steps and expected results used to verify a function.
Defect log
PROJECT MANAGEMENT
The tracked list of issues found in testing, with severity, owner, and status.
Go-live
PROJECT MANAGEMENT
The date the new system becomes the system of record for live processing.
Hypercare
PROJECT MANAGEMENT
The heightened support period immediately following go-live.
RACI
PROJECT MANAGEMENT
A matrix naming who is responsible, accountable, consulted, and informed.
Milestone
PROJECT MANAGEMENT
A dated checkpoint marking completion of a significant body of work.
Critical path
PROJECT MANAGEMENT
The sequence of dependent tasks that determines the earliest possible finish date.
Gantt chart
PROJECT MANAGEMENT
A timeline view of tasks, durations, and dependencies.
Sprint
PROJECT MANAGEMENT
A fixed-length iteration in which a defined set of work is completed.
Backlog
PROJECT MANAGEMENT
The prioritized list of work not yet scheduled into an iteration.
Change order

A written, priced agreement to modify scope after work has begun.
Risk register

The tracked list of potential problems with likelihood, impact, and mitigation.

The executive group that resolves escalations and approves major decisions.
